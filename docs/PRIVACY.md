# Privacidad y datos

El sistema puede tratar identificadores, licencias, aptitud médica y evidencias contractuales. Antes de un piloto se debe definir responsable y encargado, finalidad, base jurídica, información al titular, conservación, atención de derechos, transferencias, incidentes y eliminación segura conforme a la normativa peruana.

El repositorio solo admite datos ficticios. `media/`, bases locales y archivos de entorno están excluidos. En producción use almacenamiento privado, cifrado, copias controladas, mínimos privilegios, registro de accesos y política de retención. No almacene diagnósticos clínicos cuando baste registrar vigencia/apto-no apto.
