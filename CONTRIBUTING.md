# Contribuir

1. Abra un issue describiendo problema, módulo, criterio de aceptación y fuente oficial.
2. Cree una rama y no incorpore datos reales ni nombres/logotipos que sugieran aprobación de una minera.
3. Añada migración y pruebas para toda regla de cumplimiento.
4. Ejecute `ruff check .`, `python manage.py check` y `python manage.py test`.
5. Envíe un pull request explicando riesgos, evidencia y compatibilidad.

Las reglas de un cliente deben registrar fuente, versión, vigencia, criticidad y evidencia; nunca deben presentarse como requisito oficial sin documento verificable.
